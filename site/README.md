# Site theme and assets

The published site is a joint CDC/AIRA publication. Its presentation belongs to
this project and can change independently of other AIRA publications.

| Path | What it is |
|---|---|
| `theme/tokens.css` | Project theme tokens: colors, fonts, verb and finding colors. **Change the look here.** |
| `theme/mermaid-theme.json` | Mermaid diagram theme, matching the tokens |
| `vendor/aira-guide/` | Starting point copied from [`immregistries/content-publishing-templates`](https://github.com/immregistries/content-publishing-templates) **v0.15.1** (commit `ad90b7a`), `templates/guide/`: `aira.css` (AIRA Web 0.1.13), `guide.css`, `guide.js` (comments), the AIRA logo, and Mermaid 11.12.0 with its MIT license |

The vendor copy is a baseline, not a link. This project may modify it, for
example to add the multi-page, card-level comment mode. When it does, record
the change here.
