Programs should define a clear purpose before investing in VIS data-quality monitoring. Because VIS data does not affect forecasting, vaccine validity, or downstream IIS functions, programs should carefully assess whether enhanced completeness provides meaningful value. Where VIS information is programmatically useful, IIS must receive both accurate and inaccurate submissions to identify issues and correct them through data-quality operations.

Conformance statements

  1. SHOULDIIS SHOULD align VIS-related policies with specific program needs, not general data-quality expectations.s1
  2. SHOULDIIS SHOULD avoid making VIS data a structural requirement for vaccination reporting.s2
  3. SHOULDIIS SHOULD treat VIS data discrepancies as quality-improvement opportunities, not message-level errors.s3
  4. SHALLIIS SHALL continue to accept and store administered vaccinations regardless of VIS completeness or accuracy.s4
