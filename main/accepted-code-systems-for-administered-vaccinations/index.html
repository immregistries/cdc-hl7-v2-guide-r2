4.6.2.4.1 Accepted Code Systems for Administered Vaccinations

Conformance statements

  1. SHALLIIS SHALL accept CVX codes to represent administered vaccinations.s1
  2. SHALLIIS SHALL accept NDC codes to represent administered vaccinations.s2
  3. MAYIIS MAY accept CPT codes for administered vaccinations to support legacy interfaces.s3
  4. SHALLIIS SHALL be capable of accepting an administered vaccination reported with only a valid CVX code and no NDC.s4
  5. SHALLIIS SHALL be capable of accepting an administered vaccination reported with only a valid NDC and no CVX.s5
  6. SHALLWhen both CVX and NDC are submitted for an administered vaccination, IIS SHALL inspect the submitted values to ensure they correlate to the same vaccine concept.s6
