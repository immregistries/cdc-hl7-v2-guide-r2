3.5.2.3 Z31 - Return a List of Candidates

A Z31 response indicates that the IIS was unable to identify exactly one high-confidence patient match. Instead, one or more possible matching patient records were found, and IIS policy allows limited identifying information for those candidates to be returned.

A candidate list typically represents a small, resolvable number of possible matches, not an open-ended result set. In most cases, a Z31 response contains only two or three candidates, patient records that are similar enough to the submitted identifying information that the IIS cannot confidently select one, but distinct enough that a user reviewing the candidates can reasonably identify the correct match. This is the expected, ordinary use of Z31 and reflects normal ambiguity in patient matching, such as family members with similar names and addresses, rather than a data quality problem.

"Too many matches," by contrast, describes a different situation: the number of possible candidates exceeds what can be usefully presented for manual selection, whether because the submitted identifying information was too sparse to narrow the search meaningfully, or because the number of candidates exceeds the limit requested in RCP-2 or configured by the IIS. In this situation, returning a long, unwieldy candidate list would not help a user identify the correct patient and could itself introduce privacy and matching risk. For this reason, an IIS facing more candidates than it can reasonably return does not send an oversized Z31; instead, it returns a QAK-2 value of TM (Too Many Found), signaling that the query itself should be refined with more specific identifying information rather than resolved by manual review of a long list.

Z31 responses do not include immunization history. They are intended to support user-assisted resolution of ambiguous matches. To retrieve immunization data, the querying system must select a specific candidate and issue a follow-up query for that patient.

Conformance statements

  1. MAYA Z31 (candidate-list) response MAY be returned in response to either a Z34 (Request a Complete Immunization History) or a Z44 (Request Evaluated Immunization History and Forecast) query when the IIS cannot identify a single high-confidence match.⚑s1
