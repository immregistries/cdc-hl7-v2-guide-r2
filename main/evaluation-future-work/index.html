Specific areas where further guidance may be developed include requiring a standardized reason code when a dose is invalid, standardizing the coding and counting of dose numbers and dose series counts, expanding the set of dose validity codes, requiring reasons for recommendations in certain cases, and clarifying or adding additional status categories within immunization series. Current guidance recommends using LOINC Answer codes for these status categories; future guidance may expand or replace these codes.

Conformance statements

  1. SHALLThe vaccine type SHALL be reported using the designated LOINC code specified in Chapter 7 (OBX table).⚑s1
  2. SHALLThe vaccine-type observation SHALL be placed first within each evaluated group.⚑s2
  3. SHALLCVX SHALL be used in OBX-5; the CVX selected SHOULD represent the most appropriate antigen-level CVX. When an exact product formulation is not known, implementers MAY use an unspecified formulation CVX.⚑s3
  4. SHOULD NOTThe deprecated component-level vaccine-type LOINC code SHOULD NOT be returned (see Chapter 7 for additional detail).⚑s4
