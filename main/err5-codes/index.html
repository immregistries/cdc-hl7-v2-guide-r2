Appendix D

National ERR-5 Application Error Codes

Pending publication. These codes are from version 2026-07-06 of AIRA's National Set of ERR-5 Application Error Codes for Immunization ACK Messaging, which is being prepared for posting on the AIRA repository. The published set is authoritative; this page will be updated from it.

ERR-5 identifies what the problem was, using a code from this national set (3.3.3.4 ERR-5: Application Error Code). Each code has an implementation priority: IIS SHALL implement High priority codes, SHOULD implement Medium priority codes, and MAY implement Low priority codes. Implementing a code means returning it when the condition is detected; the ERR-4 severity, and whether the data is accepted, remain local decisions.

If a concept is not in the set, ask AIRA to add a code (info@immregistries.org) rather than defining a local one. Codes with status Not Specific are general and should be used only when no more specific code applies; Deprecated and Do Not Use codes should not be used.

280 codes: 20 High, 63 Medium, 184 Low, 13 not applicable (deprecated or do not use).

Compared with the IGAMT value set

The value set bound to ERR-5 in the profiles, HL70533_IZ01, has 67 codes, 67 of them in the national set. 213 national codes, including 16 of the 20 High priority codes, are not in it. The IGAMT column below marks the codes the value set has.
