A Example Messages

Draft example messages from CDC's example list and the drafted samples. Each example appears on the sections it illustrates. Examples drafted as clips (only the segments that matter) are completed from a base message, so that every example is a whole message. Each one is checked against the IGAMT profiles on every build: segments, required and unsupported fields, codes, date and time formats, conformance statements, and OBX co-constraints.
