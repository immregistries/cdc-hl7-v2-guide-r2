Glossary and Abbreviations

This appendix provides an alphabetical reference to the abbreviations and terms used throughout this Implementation Guide. Many terms used in immunization messaging have a specific, foundational meaning in this guide; where a term is fully defined in Key Terms or in a narrative section, this appendix gives a brief gloss and points to that section rather than restating the definition.

Abbreviations

AA

Application Accept. An MSA-1 value indicating that a VXU was accepted with no issues requiring correction or resubmission. See Acknowledgement (ACK) Message Profile.

ACK

Acknowledgement. An HL7 v2 message type used to communicate the outcome of processing a submitted message. See Acknowledgement Processing Overview and Acknowledgement (ACK) Message Profile.

ADT

Admission, Discharge, Transfer. An HL7 v2 message type outside the scope of this guide.

American Medical Association.

AR

Application Reject. An MSA-1 value indicating that a VXU was rejected because core intent was not fulfilled. See Acknowledgement (ACK) Message Profile.

Too Many (TM)

A QAK-2 value indicating that the number of possible candidate matches exceeded the applicable limit, signaling that the query should be refined rather than resolved through manual review. See Z31 - Return a List of Candidates.

Usage Designation

The VXU message structure identifier for Vaccination Record Update (Unsolicited Immunization Update). See Vaccination Record Update (VXU) Message Profile.
