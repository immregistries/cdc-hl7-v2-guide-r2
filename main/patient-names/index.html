4.5.2.1 Patient Names

Quality review 1 warning · 1 note

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Warning TAB Patient Name (PID-5) Updates to Support Patient Matching (Table 1 compared with the IGAMT value set): Conflict. HL70200_IZ01 (closed) does not include REL, MSK, or NOUSE, which the TAB allows (MAY), so they cannot be sent. It allows D (P), which the TAB says SHOULD NOT be supported, and leaves out NAV, TEMP, BAD, F, and K. It also has R and S (both E), which are not in the TAB's table.
    ConflictAction: IGAMT
    TAB Table 1 gives the usage of each HL70200 code for PID-5 (R for L; P for the others allowed; E for F, I, K, P).
    Recommendation Align HL70200_IZ01 with Table 1, including its usage for each code.

    See the TAB comparison

    qf-tab-pn-05
  • Note TAB Patient Name (PID-5) Updates to Support Patient Matching (Examples): Missing. The guide has figure 22 of the name types but none of these PID-5 examples.
    MissingAction: Narrative
    TAB PID-5 examples: 'L' alone; 'L' with a preferred first, last, or full name ('N'); 'L' with a maiden name ('M'); all three; newborn names for single and twin births, alone and with the legal name; and José González sent with accents and returned with or without them.
    Recommendation Add the TAB's examples to appendix A, linked from 4.5.2.

    See the TAB comparison

    qf-tab-pn-17

The PID-5 field represents the patient's name and may repeat for multiple name types. Correct classification of each name type allows the IIS to understand how different systems represent the same individual and to reconcile records accordingly.
