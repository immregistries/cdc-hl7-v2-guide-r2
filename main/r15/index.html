Changes from Release 1.5

How this guide differs from the HL7 Version 2.5.1 Implementation Guide for Immunization Messaging, Release 1.5, 2018 Update.

What Release 1.5 means here

For format and validation (message structure, usage, cardinality, data types, lengths, value sets, and conformance statements), Release 1.5 is the set of conformance profiles NIST built from the 2018 Update for its Immunization Test Suite. NIST studied the guide closely to build them, and they are what immunization systems were tested and certified against, so they are the baseline. Where the tables in the 2018 document differ from NIST's reading, NIST's profiles are used and the difference is not reported.

For everything else, the guidance in the narrative, Release 1.5 is the 2018 Update document published by CDC.

Codes in externally maintained code systems (CVX, MVX, NDC, cdcgs1vis) change all the time and are not compared; only a change in which of them a field uses is shown.

Summary

  • 11 changes to message structure (segments and groups)
  • Conformance statements: 14 changed, 2 removed, 5 added, 2 reworded, 5 renumbered, 14 split into parts, 18 unchanged
  • 97 usage changes: 77 tightened, 20 loosened, the rest changed in other ways
  • 57 changed conditions (predicates) for conditional (C) elements
  • 14 cardinality changes and 3 data type changes
  • 51 changes to the value sets fields use, and 22 changes to the codes in them
  • 39 changed lengths; 220 elements no longer state a length
  • Narrative guidance (below): 47 changed, 11 not carried forward, 6 partly carried forward, 20 expanded, 23 the same

Fields and components are compared where either guide constrains them (usage other than O or X); components are compared two levels deep. A change that is the same in several profiles is shown once.
