3.2.4.2 Non-Identifying Vaccination Fields

Quality review 3 warnings · 2 notes

Findings from automated and editorial checks, for the authors. Not part of the guide.

  • Warning MIROW guide Data Quality Assurance in Immunization Information Systems (BR127 - Vaccination event dosage): Partly covered. RXA-6 and RXA-7 are required in the administered RXA flavor, but the narrative says nothing about either beyond listing dose volume as a non-identifying field, and does not say how to send an unknown amount. MIROW's remark relies on the Release 1.5 convention of 999.
    Partly coveredAction: Narrative
    Best practice An administered vaccination should have a dosage that is a positive number with a unit of volume (for example, mL). A value of 999 in HL7 means the amount was not filled in.
    Recommendation State in the guide that RXA-6 carries the dose volume with its unit in RXA-7, and that 999 is sent when the amount is unknown (or decide otherwise), consistent with MIROW BR127.

    See the MIROW comparison

    qf-mirow-dqa-21
  • Warning MIROW guide Data Quality Assurance in Immunization Information Systems (BR129, BR130, BR132 - Lot number content (Appendix K)): Missing. The guide names lot number quality as a problem conformance cannot solve but says nothing about what RXA-15 should contain. RXA-15 may repeat in the administered flavor (for a unit-of-sale and a unit-of-use lot), which fits BR130 only if each repetition holds one lot number. ERR-5 code 3554 (lot number invalid) exists to report violations.
    MissingAction: Narrative
    Best practice A lot number should contain only letters, digits, and dashes (no spaces around a dash); hold a single lot number and nothing else; and not be prefixed, appended, or embedded with extraneous strings.
    Recommendation Add to Non-Identifying Vaccination Fields (or the RXA-15 field notes) that each repetition of RXA-15 carries exactly one lot number as printed on the product, with no other text, and point to MIROW BR129-BR132 and Appendix K.

    See the MIROW comparison

    qf-mirow-dqa-24
  • Warning SISC guidance Guidance on Unit of Sale/Unit of Use Lot Numbers (Document Use): Missing. The guide treats the same unit-of-use and unit-of-sale problem for NDCs, and IGAMT makes RXA-15 (lot number) required for administered doses, but the guide never says which lot number RXA-15 carries, or that it may differ from the inventory lot.
    MissingAction: Narrative
    Guidance Many systems use the unit-of-sale lot number for ordering and inventory but the unit-of-use lot number at administration. Where the two differ, the lot number recorded for a vaccination is the unit-of-use lot.
    Recommendation State that RXA-15 carries the lot number of the unit administered (the vial or syringe), that for some products this differs from the unit-of-sale lot used for inventory, and link this guidance.

    See the SISC guidance comparison

    qf-sisc-lot-01
  • Note MIROW guide Immunization Information System Inventory Management Operations (BR711 (remarks) - Lot number field used for other purposes): Partly covered. Now that funding source has its own OBX, there is no reason to put it in RXA-15. The guide doesn't say that RXA-15 carries only the lot number, as the 2022 data quality guide asks (see mirow-dqa-24).
    Partly coveredAction: Narrative
    Best practice Some EHRs extend the lot number field to mark public or private stock. The IIS needs to separate the real lot number from the public/private designation and record them in two fields.
    Recommendation Covered by the recommendation in mirow-dqa-24. When adding it, say that stock designations belong in the funding source OBX, not in RXA-15.

    See the MIROW comparison

    qf-mirow-im-09
  • Note TAB Scenarios for Updates and Queries (Appendix, Table 4: Non-identifying vaccination record fields): Partly covered. The guide lists the RXA and RXR fields and "Vaccine information statement and related OBX elements", but not funding source or eligibility, or the LOINC codes. Section 4.6.4 says any field outside the identifying list can be sent as an update, so the meaning is the same.
    Partly coveredAction: Narrative
    TAB RXA-6 dose volume, RXA-15 lot number, RXA-16 expiration date, RXA-17 manufacturer, RXR-1 route, RXR-2 site, and the OBX observations for VIS (69764-9), VIS given date (29769-7), funding source (30963-3), and dose level eligibility (64994-7).
    Recommendation List the four OBX observations with their LOINC codes in 3.2.4.2, as the TAB does.

    See the TAB comparison

    qf-tab-sc-16

Changes to these fields are handled via update:

Dose volume (RXA-6)

Lot number (RXA-15)

Expiration date (RXA-16)

Manufacturer (RXA-17)

Route (RXR-1)

Site (RXR-2)

Vaccine information statement and related OBX elements

Note: All identifying and non-identifying vaccination fields discussed in this section are also designated as CDC Core Data Elements, underscoring their foundational role in accurate vaccination event identification.
