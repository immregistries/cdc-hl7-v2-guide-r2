3.2.4.2 Non-Identifying Vaccination Fields

Changes to these fields are handled via update:

Dose volume (RXA-6)

Lot number (RXA-15)

Expiration date (RXA-16)

Manufacturer (RXA-17)

Route (RXR-1)

Site (RXR-2)

Vaccine information statement and related OBX elements

Note: All identifying and non-identifying vaccination fields discussed in this section are also designated as CDC Core Data Elements, underscoring their foundational role in accurate vaccination event identification.
