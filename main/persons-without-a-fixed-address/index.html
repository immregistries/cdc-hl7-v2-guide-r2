4.5.3.3 Persons Without a Fixed Address

  • Note 3 requirements were written as paragraphs in the draft and are shown here as conformance statements (wording unchanged): s1, s2, s3.qf-statement-from-paragraph-d899f63a

HL7 v2 does not currently define a standard mechanism for representing patients without a fixed address. In practice, placeholder values (e.g., "HOMELESS") or surrogate addresses (e.g., clinic locations) are sometimes used, but these practices are inconsistent and reduce data quality.

Until community consensus is reached, IIS must manage these patterns pragmatically rather than enforcing rigid submission rules.

Conformance statements

  1. SHALL NOTIIS SHALL NOT reject messages based solely on placeholder or surrogate address values.s1
  2. SHOULDIIS SHOULD use cleansing services to detect known placeholder patterns.s2
  3. SHOULDIIS SHOULD establish local policies for managing repeated use of clinic or landmark addresses.s3
