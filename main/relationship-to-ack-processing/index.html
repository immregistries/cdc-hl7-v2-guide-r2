Usage designations describe expectations for population and processing. They do not, by themselves, determine message acceptance or rejection. When issues are identified, IIS SHALL report them using ERR segments. The presence of an ERR segment does not, by itself, indicate that the message was rejected; ERR segments may appear in acknowledgement messages even when a message is accepted and processed, such as when the issue reported is a warning or informational notice. The severity assigned to those issues-and the resulting message disposition-are defined in Section 3.3 (Acknowledgement Message Profile).

By clearly separating usage, validation scope, and ACK severity, this guide supports consistent implementation, realistic testing, and a shared understanding of how IIS actually operate today.
