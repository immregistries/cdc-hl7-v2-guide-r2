4.5.5.1 Value Sets and Field Usage

Quality review 1 warning · 4 notes

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Warning Statement s1 "Use the CDCREC value set": the profiles bind category-only value sets, without MENA or the detailed codes. The narrative talks about "the CDCREC value set", including detailed subcategories and Middle Eastern or North African (MENA) as a top-level race category. The profiles bind PID-10 to PHVS_RaceCategory_CDC_NullFlavor (6 OMB categories, Other Race, and three unknown codes) and PID-22 to PHVS_EthnicityGroup_CDC_Unk. Neither contains MENA or any detailed code. Both are Static/Open, so a validator would likely only warn, but readers cannot see what is allowed.
    GapAction: Narrative and IGAMT
    Narrative "Race (PID-10) SHALL use the CDCREC value set." "IIS SHOULD support the MENA race code as a top-level category." "IIS SHALL accept additional valid CDCREC codes."
    IGAMT export
    • PID-10: PHVS_RaceCategory_CDC_NullFlavor (9 codes: 1002-5, 2028-9, 2054-5, 2076-8, 2106-3, 2131-1, ASKU, PHC1175, UNK); Static, Open.
    • PID-22: PHVS_EthnicityGroup_CDC_Unk (5 codes); Static, Open.
    Recommendation Name the bound value sets in the narrative (or rename them in IGAMT). Decide whether MENA and the detailed CDCREC codes belong in the binding (Dynamic), and whether 2131-1 Other Race remains.

  • Note 3 requirements were written as paragraphs in the draft and are shown here as conformance statements (wording unchanged): s1, s2, s3.qf-statement-from-paragraph-65a9b19b
  • Note Statement s2 The text calls PID-22 "Ethnicity"; its name in the profiles is "Ethnic Group". Using the HL7 name alongside the role name (for example, "MSH-4 (Sending Facility), the submitting organization") helps readers match text to the tables.

Race and ethnicity are transmitted using distinct HL7 fields and standardized code systems. IIS interoperability depends on consistent use of the CDCREC value set rather than legacy HL7 tables. See Section 7.4, Value Sets, for the authoritative Race and Ethnicity codes.

Conformance statements

  1. SHALLRace (PID-10) SHALL use the CDCREC value set.⚑s1
  2. SHALLEthnicity (PID-22) SHALL use the CDCREC value set.⚑s2
  3. SHALL NOTSystems SHALL NOT use HL70005 for race or ethnicity coding.s3
