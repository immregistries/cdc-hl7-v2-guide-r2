4.7.8.6 Additional Optional Forecast Details

Quality review 1 note

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Note 4 requirements were written as paragraphs in the draft and are shown here as conformance statements (wording unchanged): s1, s2, s3, s4.qf-statement-from-paragraph-c93698ca

Additional fields may be included to describe how the CDS engine interpreted the patient's status. These fields are useful but not standardized, and their meaning should be treated as explanatory rather than authoritative. Series name, total number of doses in series, and dose number of next event may help clarify CDS behavior but may not align across implementations. Schedule used is similarly optional; only one schedule code is defined today (ACIP), and it does not capture local adaptations that are common in practice.

Conformance statements

  1. MAYThe IIS MAY return series name.s1
  2. MAYThe IIS MAY return total number of doses in series.s2
  3. MAYThe IIS MAY return dose number for the next event.s3
  4. MAYThe IIS MAY return the schedule used, with the understanding that it has limited reliability.s4
