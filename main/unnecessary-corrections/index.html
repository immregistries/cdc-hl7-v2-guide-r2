4.6.4.6 Unnecessary Corrections

Submitting systems sometimes generate corrections when no vaccination information has changed, such as when a user opens and saves a record without modifying it. These messages add traffic and can increase the risk of out-of-order processing or inconsistent histories. Corrections are limited to meaningful changes or actual retraction of a previously submitted record.

Meaningful correction activity represents a finalized change or completed retraction of the source record. Some clinical systems create temporary states while a user edits or recharts a vaccination. Transmitting each intermediate state can produce out-of-order processing or inconsistent histories. The submitting system communicates the finalized state or completed retraction-and-replacement workflow rather than each temporary state.

Conformance statements

  1. SHALL NOTSubmitting systems SHALL NOT send an update or delete unless vaccination information has changed or the source record has been retracted.s1
