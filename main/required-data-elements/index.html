4.8.7.2 Required Data Elements

Quality review 1 warning · 2 notes

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Warning The refusal slice also requires RXA-6 = 999, which the refusal section does not list. The Z22 slicing selects the refusal flavor (RXA_IZ01_Ref) only when RXA-20 = 'RE' and RXA-6 = '999', and constraint IZ-48 requires RXA-6 = 999 whenever RXA-20 = 'RE'. The refusal section's list of minimum elements leaves out RXA-6. A refusal sent with any other amount is not validated against the refusal flavor (so RXA-18 is not checked as required) and fails IZ-48. The same applies to contraindicated (NA, CVX ≠ 998) and no-vaccination (NA, CVX 998) groups, which both also select on RXA-6 = 999.
    GapAction: NarrativeAnswers Word comment 57
    Narrative "The minimum required elements are: ORC-3=9999 – Filler Order Number; RXA-3 …; RXA-5 …; RXA-18 – Reason for refusal; RXA-20 = 'RE'." Comment 57: "Double-check this is how the slicing logic is set up."
    IGAMT export
    • Slice RXA_IZ01_Ref: RXA-20 = 'RE' AND RXA-6 = '999'; RXA-18 R [1..*] in this flavor.
    • IZ-48 (RXA_IZ01): if RXA-20 = 'RE' then RXA-6 SHALL be '999'.
    • IZ-45 (Z22 message): if RXA-20 in ('NA','RE') then ORC-3.1 SHALL be '9999'.
    Recommendation The slicing is set up consistently with IZ-45 and IZ-48. Add "RXA-6 = 999 – Administered amount" to the refusal list, and state the RXA-6/ORC-3 values in the non-administration sections too. Consider whether the slice should key on RXA-20 alone, so that a wrong RXA-6 is reported by IZ-48 rather than silently changing which flavor applies.

Refusals must identify both when the vaccination was declined and what vaccination was refused. The minimum required elements are:

ORC-3=9999 – Filler Order Number.

RXA-3 - Date the vaccination would have been administered if accepted.

RXA-5 - Vaccine that was offered and refused.

RXA-18 - Reason for refusal

RXA-20 = "RE" - Indicator that the vaccination was refused
