4.3.1 Dynamic Code Sets (Evolving Code Sets Requiring Active Maintenance)

Dynamic code sets are those expected to change over time as clinical practice, products, or policy evolve. These value sets are typically maintained by an external authority and updated independently of this implementation guide. New codes may be introduced, deprecated, or retired on a regular cadence, and systems must be designed to incorporate those changes without requiring specification revisions.

Dynamic code sets are used where the domain itself evolves. Vaccine products, manufacturers, billing codes, and disease classifications all fall into this category. Because these codes directly affect clinical meaning, failure to recognize new values can compromise immunization history completeness, evaluation accuracy, or reporting correctness.

Examples of dynamic code sets include CVX, NDC, MVX, and CPT.

Conformance statements

  1. SHALLSystems (including IIS and submitting systems) SHALL maintain a process to monitor and incorporate updates to dynamic code sets relevant to immunization messaging.s1
  2. SHALL NOTSystems SHALL NOT hard-code dynamic code values into application logic without a defined update mechanism.s2
  3. SHALLSystems SHALL validate received values for dynamic code sets against their current authoritative versions.s3
  4. SHALLWhen a value from a dynamic and closed code set (e.g., CVX or NDC) is not recognized, the IIS SHALL generate an error or warning indicating that an unexpected or unknown value was received.s4
