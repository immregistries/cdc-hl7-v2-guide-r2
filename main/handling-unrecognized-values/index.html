Not all unrecognized values indicate the same level of risk. The appropriate response depends on the stability, extensibility, and operational role of the value set, as well as the usage designation of the field in which it appears. Some variation is expected and manageable, particularly for open and dynamic sets in fields with usage RE or O. In contrast, unrecognized values in static or closed sets represent structural or semantic errors that must be corrected.

Conformance statements

  1. SHALLSystems (including submitting systems and IIS) SHALL vary response severity based on the classification of the value set and the usage of the field.s1
  2. SHOULDIIS SHOULD be tolerant of unrecognized values in open and dynamic valuesets when the field usage is RE or O and SHALL avoid excessive, non-actionable notifications.⚑s2
  3. SHALLQuerying systems SHALL be capable of handling locally extended values in responses and SHALL not assume that only nationally defined codes will be returned.⚑s3
