3.5.2.5 Z42 - Return Evaluated Immunization History and Forecast

A Z42 response indicates a successful query for a Z44 profile. The IIS has identified a single, high-confidence patient match and is able to return the complete immunization history along with evaluation and forecast results.

Evaluation and forecast content are generated by the IIS clinical decision support logic using the schedule selected and maintained by the IIS. This response represents the full clinical decision support outcome available at the time of the query.
