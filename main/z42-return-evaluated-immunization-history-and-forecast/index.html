3.5.2.5 Z42 - Return Evaluated Immunization History and Forecast

Quality review 1 issue

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Issue Z42's co-constraint table has no conditions, so every history dose needs a forecast group. Z22 and Z32 select a co-constraint table by the kind of Order Segment Group (administered, refused, …). Z42 has one unconditional table. Its "Immunization Forecast Results" group is R [1..*], so it applies to every ORC/RXA group in the response: each returned dose would need a forecast, and evaluation results are allowed in the forecast group. Z42 also has no rows for eligibility, funding, VIS, comments, or contraindications, which Z32 returns.
    IGAMT export defectAction: IGAMT
    Narrative 4.7.8.1: "All forecast information SHALL be returned under a single ORC/RXA order group." 4.4.4.5 and 4.4.4.6 separate "Immunization Event with Evaluation" from "Forecast".
    IGAMT export
    • Z42 OBX at HISTORY_FORECAST.HISTORY_FORECAST_OBSERVATION: one simple table; groups Immunization Evaluation Results S [0..*], Immunization Forecast Results R [1..*], Conditions: Patient Observations O [0..*].
    Recommendation Make the Z42 tables conditional like Z32: evaluation for administered or historical doses (RXA-20 CP or PA), and forecast for the CVX 998 group. Add the event-level observations that Z32 allows.
    qf-igamt-z42-unconditional

A Z42 response indicates a successful query for a Z44 profile. The IIS has identified a single, high-confidence patient match and is able to return the complete immunization history along with evaluation and forecast results.

Evaluation and forecast content are generated by the IIS clinical decision support logic using the schedule selected and maintained by the IIS. This response represents the full clinical decision support outcome available at the time of the query.
