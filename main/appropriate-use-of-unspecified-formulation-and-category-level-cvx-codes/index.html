4.6.2.2.3 Appropriate Use of Unspecified Formulation and Category-Level CVX Codes

Quality review 1 note

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Note In the draft, explanatory text continues after the conformance statements. Cards show statements after the narrative, so check that the order still reads well.qf-statements-mid-section-bcb1bf2d

Unspecified Formulation or category-level CVX codes are appropriate for historical vaccinations when the exact formulation or product cannot reasonably be determined. They are also appropriate when the code represents the most specific CVX available for that vaccine concept, and for representing foreign vaccinations when no more specific CVX code exists.

Use of Unspecified Formulation and Category-Level CVX Codes for Administered Vaccinations

Use of a broader CVX code is preferable to omitting the vaccination entirely when specific product information is unavailable.

IIS Acceptance and Data Quality Monitoring

Conformance statements

  1. SHALLSubmitting systems SHALL use the most specific CVX code they know to be accurate for an administered vaccination.s1
  2. SHOULD NOTSubmitting systems SHOULD NOT use Unspecified Formulation or broad category-level CVX codes for newly administered vaccinations when a more specific CVX code is known at the time of documentation.s2
  3. SHALLIIS SHALL accept Unspecified Formulation and category-level CVX codes when they represent the best available information.s3
  4. SHALL NOTIIS SHALL NOT reject vaccination records solely because an Unspecified Formulation or category-level CVX code is used.s4
  5. SHOULDIIS SHOULD monitor use of Unspecified Formulation and category-level CVX codes, particularly for administered vaccinations, as part of ongoing data-quality review.s5
  6. SHOULDIIS SHOULD work with submitting systems when routine use of broader CVX codes indicates loss of available specificity or workflow issues.s6
