The CVX code set evolves over time as new vaccines are introduced, existing products are retired, and status designations change. To ensure uninterrupted interoperability and accurate immunization histories, IIS and submitting systems must remain current with CVX updates published by CDC. CDC provides multiple mechanisms to notify stakeholders of CVX changes, including publication services and downloadable code set updates, which systems are expected to monitor and incorporate.

Timely adoption of CVX updates allows submitting systems to begin using new codes without workarounds and ensures that IIS can correctly receive, interpret, and process vaccination records. Maintaining CVX currency also supports consistent evaluation, forecasting, and reporting as clinical guidance and product availability evolve.

Conformance statements

  1. SHALLIIS SHALL support newly published Active CVX codes within 30 days of CDC publication, provided the corresponding CDSi supporting data required to evaluate and forecast the CVX code are available.s1
  2. SHALLIIS SHALL support newly published Inactive CVX codes within 30 days of CDC publication so that historical and category-level records can be recorded accurately.s2
  3. SHOULDSubmitting systems SHOULD plan for timely adoption of newly published CVX codes in alignment with CDC publication schedules.s3
  4. SHALLIIS SHALL preserve CVX codes recorded in patient immunization histories indefinitely, even after those codes become inactive.s4
  5. SHALL NOTIIS SHALL NOT modify historical CVX values solely due to status changes in the CVX code set.s5
  6. SHALLIIS SHALL ensure that historical vaccination records remain interpretable over time.s6
  7. SHALLIIS SHALL maintain CVX status information (e.g., Active, Inactive, Non-US, Pending, Never Active) consistent with the CDC-published code set.s7
  8. SHOULDIIS SHOULD track effective dates and status changes for CVX codes to support accurate interpretation of historical records.s8
  9. SHOULDIIS SHOULD ensure that internal mappings and decision support configuration remain aligned with current CVX status information.s9
  10. SHOULDIIS and submitting systems SHOULD monitor CDC CVX publications and update mechanisms to remain current with code set changes.s10
  11. SHOULDIIS SHOULD encourage submitting systems to align code usage with current CDC-published CVX values to minimize data quality issues and rejected submissions.s11
