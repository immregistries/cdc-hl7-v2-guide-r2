4.6.4.4 Handling Delete Requests

A delete retracts a source record; it does not necessarily direct physical removal of the entire consolidated vaccination event. If other source records continue to support the same vaccination, the IIS can retain the event or the information supported by those remaining sources.

When the source record cannot be identified confidently or a requested correction cannot be applied, the IIS communicates the outcome so that the submitting system can determine whether manual follow-up is needed.

Conformance statements

  1. SHALLIIS SHALL support processing delete requests for vaccination records previously reported by the submitting source.s1
  2. SHOULD NOTSubmitting systems SHOULD NOT send a delete for a vaccination record originally reported by another source.s2
  3. SHOULDWhen an update or delete cannot be applied, IIS SHOULD return an acknowledgment that explains the outcome and indicates when manual follow-up is required.s3
