2.4.3 Fault Handling and Error Responses

Quality review 4 notes

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Note Statement s4 Its subject is "Transport-level faults", not a system or party, so it is unclear who must comply. Naming the responsible party (for example, "Submitting systems SHALL …" or "IIS SHALL …") makes the requirement testable.qf-no-actor-0cb1fa26
  • Note Narrative uses "must", which reads as a requirement. If it is one, state it as a conformance statement; otherwise consider softer wording.
    See the CDC SOAP Transport Specification for the complete definition of each fault type, including its specific parameters (Code, Reason, and Detail) and the corresponding obligations for which systems must be able to throw versus catch each fault.
    qf-normative-prose-02cb4af2
  • Note 4 requirements were written as paragraphs in the draft and are shown here as conformance statements (wording unchanged): s1, s2, s3, s4.qf-statement-from-paragraph-278be7cc
  • Note In the draft, explanatory text continues after the conformance statements. Cards show statements after the narrative, so check that the order still reads well.qf-statements-mid-section-980818ed

Transport-level errors are reported using SOAP Faults. Message-level issues are reported in HL7 v2 ACKs.

See the CDC SOAP Transport Specification for the complete definition of each fault type, including its specific parameters (Code, Reason, and Detail) and the corresponding obligations for which systems must be able to throw versus catch each fault.

A positive SOAP response confirms only successful transport, not HL7 v2 message acceptance.

Conformance statements

  1. SHALLIIS SHALL return a SOAP Security Fault when authentication fails.s1
  2. SHALLIIS SHALL use other defined SOAP Faults (Unsupported Operation, Message Too Large, Unknown Fault) as appropriate.s2
  3. SHALLSending systems SHALL be able to receive and handle all defined SOAP Faults.s3
  4. SHALLTransport-level faults SHALL indicate the message was not transmitted and require resubmission after correction.⚑s4
