4.8.7.4 Query and Response Behavior

Quality review 1 issue · 1 note

Findings from automated and editorial checks, for the authors. Not part of the guide.

  • Issue Statement s1 TAB Returning IIS Patient Immunization Record Information in a Z32 and Z42 RSP (Table 1: Immunization types (refused)): Conflict. The guide says "IIS SHOULD NOT return refusal records in query (RSP) responses" and "Querying systems SHALL NOT expect refusals to be returned", because refusals "have no role in clinical query/response exchanges". The TAB says the opposite. (The CDS in RSP Alignment TAB also lists refusals among the non-CDS order groups that follow the history.)
    ConflictAction: CDC decision
    TAB Refused immunizations ('RE') SHOULD be returned.
    Recommendation CDC and SISC decide. If the guide's position stands, it changes a published TAB and should say so; otherwise change 4.8.7.4 to the TAB's SHOULD.

    See the TAB comparison

    qf-tab-rr-03
  • Note 2 requirements were written as paragraphs in the draft and are shown here as conformance statements (wording unchanged): s1, s2.qf-statement-from-paragraph-cb0b4bd7

Refusals have no role in clinical query/response exchanges between EHRs and IIS. They are not considered actionable data for patient care.

Conformance statements

  1. SHOULD NOTIIS SHOULD NOT return refusal records in query (RSP) responses.⚑s1
  2. SHALL NOTQuerying systems SHALL NOT expect refusals to be returned.s2
