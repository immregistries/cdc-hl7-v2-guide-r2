4.6 Immunization Information

The primary purpose of reporting immunization information to an IIS is to build and maintain a complete immunization history for each patient. IIS receive vaccination data from multiple sources, including historical records transcribed from paper or prior systems, and may receive the same immunization event more than once. Consolidating these submissions into a single, coherent history is a core IIS responsibility and a necessary complement to patient record matching.

In addition to supporting accurate histories, immunization information enables IIS program operations and monitoring, particularly for vaccines supplied through public programs. Details about vaccine products, administration, funding source, and supporting documentation allow IIS to track vaccine usage, manage program accountability, and support clinical and public health reporting. The sections below clarify expectations for reporting immunization data elements beyond basic HL7 v2 structural requirements.
