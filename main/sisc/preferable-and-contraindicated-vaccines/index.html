Guidance on Indicating Preferable and Contraindicated Vaccines

How to indicate, in a forecast in an RSP response, the vaccine types that are preferred or contraindicated for the vaccine group being recommended.

Published PDF · Copy in this repository

The CDS in RSP TAB (September 2026) covers the same topic and keeps the same LOINC codes.

Guide sections it affects

  • 4.7.8.7 Preferred and Contraindicated Vaccine Types
  • 4.4.4.6 Forecast

Summary

The guide keeps the mechanism this guidance introduced: optional, repeatable OBX segments with LOINC 93123-8 (preferred) and 93122-0 (contraindicated) in a forecast set, with a CVX code in OBX-5, and IGAMT allows both codes in the Z42 and Z32 forecast group. It drops the cautions around them: that this is used only when both trading partners agree, that a receiver must never mistake a contraindicated vaccine for a recommended one, that preferred vaccines are not an exhaustive list the clinician must choose from, and when not to send a preferred vaccine. It also narrows OBX-5 to CVX only.

should not Preferred vaccines sent in a response are not a complete list of possible products, and the clinician need not use one of them (though they must understand the implications of using a non-preferred vaccine).		Missing Warning

The guide says these elements are used "cautiously and only when clinically justified", but not how a receiver should read them.

4.7.8.7 Preferred and Contraindicated Vaccine Types

Expectations of Support p. 1

should not Support is not required. The OBX segments are sent only when both trading partners agree there is value in it. A sender should not assume the receiver can handle them without discussion and testing; it is critical that a contraindicated vaccine is not mistaken for a recommended one. Partners may agree to exchange one kind but not the other.		Partly covered Warning

Both are MAY in the guide, so support is optional, and s4 asks IIS to document product guidance in their local IG. The safety warning is gone: a querying system that ignores unknown OBX segments is fine, but one that reads every CVX in a forecast set as recommended would show a contraindicated vaccine (93122-0) as due.

Recommendation: State that IIS return these OBX segments only to querying systems that have agreed to receive them, and that querying systems SHALL NOT present a contraindicated vaccine type as recommended.

Action: Narrative

4.7.8.7 s1, 4.7.8.7 s2, 4.7.8.7 s4

Structure of the Z42 message p. 2

should; should not Send a preferred vaccine only when there is a clear preference over other available products: not when all products are equally valid, and not when only one vaccine is available. The other attributes of the recommendation (dates, series name) apply equally to every preferred vaccine.		Partly covered Note

The guide has the first rule ("SHOULD NOT be used ... when any vaccine in the group would be equally appropriate"). It does not say to skip it when only one product exists, or that the recommendation's dates apply to every preferred vaccine.

Recommendation: Add the other two points to s1 or the narrative.

Action: Narrative

4.7.8.7 s1

Structure of the Z42 message (OBX-3, OBX-4) p. 2

OBX-3 is 93123-8 (preferred vaccine type) or 93122-0 (contraindicated vaccine type), each of which may be repeated in one recommendation. OBX-4 is the same sub-ID as the other OBX segments in the recommendation.		Covered

IGAMT allows both codes in the Z32 and Z42 forecast group.

4.7.8.7 s1, 4.7.8.7 s2, 4.4.4.6 Forecast

Structure of the Z42 message (OBX-5) p. 3

OBX-5 holds a CVX code for the vaccine (some CVX codes cover several similar products). NDCs are likely too granular but are not excluded. Only one vaccine per OBX segment; three vaccines need three segments.		Reworded Note

The guide requires CVX (SHALL), which rules out the NDCs this guidance allowed. One vaccine per segment follows from the guide's "MAY be repeated" wording.

Recommendation: Confirm that excluding NDC is intended, and record it in the change history if so.

Action: Narrative

4.7.8.7 s3

Example p. 3-4

Example forecast showing no preferred vaccine for MMR (one product), a contraindicated live intranasal influenza vaccine for an asthmatic patient, one preferred MenB product (Bexsero, not interchangeable with Trumenba), and two preferred Td products.		Out of scope

An example rather than a requirement. It would make a good example for Appendix A, which has none for these codes.
