Guidance on Unit of Sale/Unit of Use Lot Numbers

How to handle vaccines whose carton (unit of sale) and vial or syringe (unit of use) carry different lot numbers, so that a reported dose can still be matched to inventory.

Published PDF · Copy in this repository

Approved by SISC July 12, 2017; codes updated June 14, 2018. It replaces the 2015 MIROW micro-guide on validating lot numbers.

Summary

This guidance is mostly reference data for IIS and EHR developers. Its point for messaging is that the lot number recorded at administration (from the vial or syringe, the unit of use) can differ from the lot number on the carton (the unit of sale) that inventory is tracked by. The guide handles the same issue for NDCs, but says nothing about which lot number goes in RXA-15, or which lot to report for a reconstituted vaccine. It also does not point to this guidance, which developers still need for the product tables and patterns. The data in the document is from 2016 and 2018, so CDC may want to check it is still current before the guide links to it.

Requirement by requirement

The guidance saysResultIn the guide

Document Use p. 1

Many systems use the unit-of-sale lot number for ordering and inventory but the unit-of-use lot number at administration. Where the two differ, the lot number recorded for a vaccination is the unit-of-use lot.		Missing Warning

The guide treats the same unit-of-use and unit-of-sale problem for NDCs, and IGAMT makes RXA-15 (lot number) required for administered doses, but the guide never says which lot number RXA-15 carries, or that it may differ from the inventory lot.

Recommendation: State that RXA-15 carries the lot number of the unit administered (the vial or syringe), that for some products this differs from the unit-of-sale lot used for inventory, and link this guidance.

3.2.4.2 Non-Identifying Vaccination Fields, 4.6.2.3.1 Unit-of-Use and Unit-of-Sale NDCs, 4.6.2.4.3 NDC Requirements for Administered Vaccinations

Notes: Matching, Reconstituted Vaccines, and Regular Expression p. 4

Mapping a unit-of-sale lot to a unit-of-use lot is simple, but the reverse is not (except for Menveo). An IIS that knows a provider's inventory can usually match a reported unit-of-use lot to that provider's single unit-of-sale lot, and resolve any discrepancies during reconciliation (see the MIROW guide on decrementing inventory via electronic data exchange).		Out of scope Note

The guide deliberately "does not prescribe an IIS's internal inventory or lot-validation workflows", so this is IIS operations. Its inventory section would still benefit from a link to this guidance and to the MIROW inventory guide.

Recommendation: In the inventory section, link this guidance and the MIROW guide on decrementing inventory (see the MIROW alignment proposal).

Action: Narrative

4.6.4.5 Inventory and Accountability Considerations, 4.6.5.2 Vaccine Funding Source and Stock Models

Notes: Matching, Reconstituted Vaccines, and Regular Expression p. 4

For reconstituted vaccines, the unit-of-sale lot and the lot on the lyophilized vaccine powder are usually the same; the liquid diluent typically has a different lot number.		Partly covered Note

The guide requires the NDC of the lyophilized powder rather than the diluent, but does not say the same for the lot number. A submitter could report the diluent's lot with the powder's NDC.

Recommendation: Extend the reconstitution statement to the lot number: report the lot of the lyophilized powder (the active product), not the diluent.

Action: Narrative

4.6.2.4.3 s9

Tables 1-3; Appendix A p. 2-6

Tables of the vaccines whose unit-of-sale and unit-of-use lot numbers differ, with their NDCs and lot number patterns (also given as regular expressions for developers), the share of VFC volume affected (7.5 to 8.6 percent in 2015-2016), and manufacturers not surveyed. Vaccines not listed are assumed to use the same lot number on both.		Out of scope

Reference data for developers, not message requirements; the guide should point to it rather than repeat it (see sisc-lot-01). The tables date from 2016 to 2018.

4.6.2.1 Vaccine Code Systems Overview

Updating Information p. 5

Anyone who finds a vaccine with different lot numbers on the unit of sale and unit of use should tell CDC by email, with images of the packaging if possible.		Out of scope

A request for information, not guidance for messaging.
