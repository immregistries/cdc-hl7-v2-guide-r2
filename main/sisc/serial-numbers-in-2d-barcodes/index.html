AIRA/CDC Notice to the IIS Community: Serial Numbers in Unit of Sale 2D Barcodes

Notice that, under the Drug Supply Chain Security Act, unit-of-sale 2D barcodes now carry a serial number as well as the GTIN (with the NDC), expiration date, and lot number, so barcode-reading software must handle it; there is not yet a strong use case for collecting it.
