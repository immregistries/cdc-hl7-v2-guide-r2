Submitting systems may report a reaction in association with a particular administered vaccination. This creates a temporal or report-based linkage, not an assertion of causality. IIS should not assume the strength of this linkage, and IIS are not required to store or interpret these reactions. Multiple reactions may be reported for a single vaccination, each represented in a separate observation.

Patient-Level Adverse Events Not Linked to a Specific Vaccination

Some reactions occur long after the original vaccination or cannot be linked to a specific event. Submitting systems may report these at the patient-level. IIS may choose whether to store this information.

Conformance statements

  1. MAYSubmitting systems MAY submit adverse events with any immunization.s1
  2. MAYIIS MAY accept and store adverse events with any immunizationss2
  3. SHALLSubmitting systems SHALL represent each reported reaction as a separate observation.s3
  4. SHOULDIf IIS do not store associated adverse events the IIS SHOULD return an informational message indicating they are not stored.⚑s4
  5. SHOULDIf IIS store adverse event information associated with an immunization, IIS SHOULD return that information in query responses for patient-safety purposes.s5
  6. MAYSubmitting systems MAY report reactions not associated with a specific vaccination.s6
  7. SHALLSubmitting systems SHALL represent each reported reaction as a separate observation.s7
  8. MAYIIS MAY store patient-level reactions.s8
  9. SHOULDIf IIS do not store adverse events, the IIS SHOULD return an informational message indicating they are not stored.s9
  10. SHOULDIIS SHOULD return patient-level reactions in query responses for patient-safety purposes, if known.s10
