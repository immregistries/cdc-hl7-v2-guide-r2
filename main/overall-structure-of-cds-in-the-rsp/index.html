4.7.4 Overall Structure of CDS in the RSP

CDS information is embedded directly in the RSP message and follows a consistent structural pattern. Vaccination history order groups appear first, one for each administered vaccination, containing the administered vaccination and any associated evaluation information. These are followed by non-administration order groups, for example, refusals, contraindications, histories of disease, and immunities. A single Forecast order group appears last and contains all recommendation (forecast) observations.

Conformance statements

  1. SHALLRSP messages SHALL include evaluation information within each vaccination history order group when evaluation is supported for that vaccination.⚑s1
  2. SHALLRSP messages that include CDS information SHALL include exactly one Forecast order group, and the Forecast order group SHALL appear after all vaccination history order groups and after all other non-administration order groups.⚑s2
  3. SHALLVaccination history order groups SHALL be complete and unfiltered in the RSP, regardless of whether each vaccination influences a forecast.⚑s3
