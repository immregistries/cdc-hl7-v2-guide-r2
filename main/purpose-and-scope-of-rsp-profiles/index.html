RSP profiles define the structure and conformance expectations for IIS responses to Z34 and Z44 queries.

RSP content SHALL be consistent with the profile requested (Z34 or Z44). If a QBP message does not specify a query profile, the IIS MAY return either a Z32 or Z42 response as its default.

  1. SHALLIIS SHALL respond to each valid QBP with exactly one RSP message.s1
