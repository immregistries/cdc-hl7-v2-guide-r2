Occasionally, specific clinical factors justify signaling a product preference or product contraindication. These elements allow CDS engines to express more nuanced guidance, such as avoiding a live influenza vaccine in certain conditions or preferring a particular product for a special-risk patient. These should be used cautiously and only when clinically justified, as most immunization recommendations are product-agnostic.

Conformance statements

  1. MAYMAY return preferred vaccine type using LOINC 93123-8. This OBX MAY be repeated if multiple preferred products exist. Preferred vaccine type SHOULD NOT be used to indicate a specific vaccination when any vaccine in the group would be equally appropriate.⚑s1
  2. MAYMAY return contraindicated vaccine type using LOINC 93122-0. This OBX MAY be repeated to list multiple contraindicated products.⚑s2
  3. SHALLSHALL populate OBX-5 with the appropriate CVX (antigen or product) when returning preferred or contraindicated vaccine types.⚑s3
  4. SHOULDSHOULD ensure any product-specific guidance is consistent with the registry's CDS forecasting logic and documented in the Local IG.⚑s4
