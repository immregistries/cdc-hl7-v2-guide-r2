4.5.3.4 Address Types

Quality review 1 note

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Note 3 requirements were written as paragraphs in the draft and are shown here as conformance statements (wording unchanged): s1, s2, s3.qf-statement-from-paragraph-c554add9

HL7 Table 0190 defines address types (e.g., mailing, temporary). IIS use PID-11.7 to understand the intent of each address. Legacy guidance requiring the first PID-11 repetition to represent a primary address is no longer applicable.

Some address types are uncommon in IIS workflows and may have limited operational value. Their presence alone should not affect message acceptance.

Conformance statements

  1. SHALLIIS SHALL determine address type using PID-11.7.s1
  2. SHALL NOTIIS SHALL NOT reject messages solely due to uncommon or additional address types.s2
  3. MAYIIS MAY disregard address types with no operational relevance (e.g., birth location) unless explicitly negotiated.s3
