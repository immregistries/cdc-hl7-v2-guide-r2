How this was done

  1. The IGAMT export (NIST validation format) is converted to a normalized model (model/ in the repository) by tools/import_igamt.py. Nothing is edited by hand; IGAMT stays authoritative.
  2. Every field reference in the narrative and statements (for example RXA-20 or PID-5.7) is looked up in every profile and flavor, including the RXA and PID slices. The automated checks run on every build (tools/compare_structure.py).
  3. Requirements that mention a field, code, observation, or value set were read against the usage, predicates, bindings, constraints, slicing, and co-constraint tables. The judgements are recorded, with evidence, in quality/igamt-review.yml, so they can be discussed and revised.
  4. Figure 20 was transcribed (quality/transcriptions/fig-20.yml) and compared cell by cell with the OBX co-constraint tables.
