Resources

The following resources are referenced throughout this guide and are numbered in the order they are first cited. Additional general resources not directly cited in the narrative are listed at the end of this appendix.

  1. Implementation Guide and Authoring Management Tool (IGAMT)

    SITT tool used to develop HL7 Implementation Guides, including this IG. IGAMT is part of the Prometheus Standards & Interoperability Testing (SITT) suite of tools.

  2. HL7 v2 Conformance Methodology

    HL7 webpage that explains the newest HL7 v2 conformance methodology referenced in this IG and used by IGAMT.

  3. CDC Core Data Elements for Functional Standards

    CDC resource identifying the minimum data fields Immunization Information Systems (IIS) should support to enable effective immunization data exchange and interoperability.

  4. IIS Technical Guidance: Transport (SOAP)

    CDC webpage with information and specifications for using Simple Object Access Protocol (SOAP) web services to support transport of immunization data via HL7 messaging.

  5. AIRA's IIS Data Quality Best Practices

    This resource provides guidance to healthcare providers and IIS administrators on how to ensure the accuracy and completeness of immunization data within an IIS. The resource includes best practices for data entry, data validation, and data quality monitoring.

  6. HIMSS Aggregate Immunization Acknowledgment Message Reports Guidance White Paper

    Guidance on generating and interpreting aggregate reports from immunization acknowledgement messages to support interface monitoring and data quality review.

  7. Security Guidance Considerations for Immunization Information Systems

    This document explores the various issues that impact IIS security and provides guidance on industry standards and best practices for addressing common security concerns. The guidance is intended to assist IIS administrators in engaging their IT staff and vendors in conversations to ensure that an IIS is protected by appropriate security measures in accordance with industry best practices.

  8. Additional "Unknown" Race and Ethnicity Codes TAB

    Technical Advisory Bulletin providing community-accepted codes for representing unknown race and ethnicity values.

  9. Immunization Data Code Sets

    CDC webpage with current immunization-related code sets from the CDC, which includes CVX codes, MVX codes, NDC crosswalk tables, and more. Subscribe to receive updates when codes are updated.

  10. MIROW Vaccination Level Deduplication in Immunization Information Systems

    Guidance on patient and vaccination record deduplication practices within Immunization Information Systems.

Additional General Resources

The following resources are not directly cited at a specific point in the narrative but are included as general supporting material for implementers.

  1. Standards and Interoperability Testing Tools (SITT)

    Test suite used by EHR developers to ensure their immunization modules are meeting ONC's Meaningful Use requirements. The Immunization Test Suite is part of the Prometheus’ Standards & Interoperability Testing (SITT) suite of tools.

  2. General Validation Tool (GVT)

    SITT tool used to test HL7 messages based on HL7 Implementation Guides developed in IGAMT or the Test Case and Authoring Management Tool (TCAMT). GVT is part of the Prometheus’ Standards & Interoperability Testing (SITT) suite of tools.

  3. Technical Advisory Bulletins (TAB) Resources

    The technical advisory bulletins (TAB) intend to provide additional clarity on national specifications to support the interoperability of immunization information between systems.

  4. AIRA's Immunization Information System (IIS) Onboarding Toolkit

    This toolkit provides guidance to healthcare providers, EHR vendors, and other stakeholders on establishing an electronic data interface with an IIS. The toolkit includes information on the technical requirements, data elements, and messaging standards needed to successfully transmit immunization data to an IIS.

  5. CDC IIS Functional Standards

    The IIS Functional Standards describe the base standards that IIS need to support immunization programs, providers, and other stakeholders.

  6. AIRA's IIS Community of Practice

    This online forum provides a space for IIS stakeholders to share best practices, ask questions, and discuss challenges related to the implementation and operation of IIS.

  7. AIRA's Technical Assistance Training Videos

    Short videos from AIRA explaining several technical aspects of IIS and immunization data exchange, including Transport 101, SOAP WSDL 101, and NIST Test Suite.

  8. IIS Learning Hub

    Training, learning solutions and resources from the Public Health Informatics Institute for public health staff and partners supporting and using IIS. Includes eLearning modules on Fundamentals of IIS (addressing interoperability and HL7) and Advanced HL7. Quick Reference Guides on Breaking Down an HL7 Message, HL7 Messaging Acronyms, HL7 Message Profiles, and HL7 Conformance Specification Parameters are also included.

  9. Public Health Interoperability Training Catalog

    The Public Health Interoperability Training Catalog contains a list of helpful interoperability related education materials submitted by various public health programs. Materials are grouped by topic, training level (e.g., beginner, intermediate, advanced), and format (e.g., presentation, eLearning).
