Each forecasted series must begin with the vaccine type determined by the CDS engine. When indicating the vaccine type evaluated, the CVX code chosen should be the CVX that most closely matches the intended product or antigen. A forecast group is the set of OBX observations that together express the forecast for a single antigen within the ORC/RXA forecast order. Historically, an alternative "due next" code was used; it may still be included for backward compatibility but must not be used as the initiating code.

The CVX returned for the vaccine type should represent the antigen the CDS engine forecasts, often using an Unspecified Formulation CVX when appropriate. See Chapter 7 (Section 7.1.7, co-constraint table) for the authoritative LOINC codes. Forecast OBXs for the same antigen SHOULD be grouped using a common OBX-4 value. This ensures consistency between the CDS engine's forecasting logic and the content of the RSP.

Conformance statements

  1. SHALLThe forecast SHALL begin with LOINC 30956-7 (Vaccine Type).⚑s1
  2. SHALL NOTLOINC 38890-0 (Component Vaccine Type) SHALL NOT be used to initiate a forecast.⚑s2
  3. SHOULDIf needed to support legacy systems, IIS SHOULD include the legacy LOINC 30979-9 (Vaccines Due Next) after LOINC 30956-7 (Vaccine Type).⚑s3
  4. SHALLFor LOINC 30956-7, CVX SHALL be used in OBX-5, selecting the CVX most appropriate for the antigen indicated by the CDS engine (commonly an Unspecified Formulation CVX).⚑s4
  5. SHOULDThe CVX chosen SHOULD align with the CDS engine's forecasting logic.⚑s5
