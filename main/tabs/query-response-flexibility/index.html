Technical Advisory Bulletin · January 2024

Query Response Flexibility: Z31 Response for Z34 and Z44 Queries

A Z31 list of candidates MAY be returned for a Z44 query as well as for a Z34 query.

Published PDF · Copy in this repository

Summary

The guide adopts this TAB: section 3.5.2.3 says a Z31 MAY be returned for either a Z34 or a Z44 query, and leaves whether to return candidates to IIS policy. Two gaps: the TAB's one SHALL, that querying systems be prepared to receive a Z31 for either query, is not stated; and the IGAMT Z31 profile still requires QPD-1 to be Z34, so a Z31 answering a Z44 query fails validation.

Executive Summary; MAY requirements p. 1

MAY A Z31 RSP MAY be returned in response to a Z44 QBP, as well as to a Z34 QBP.		Covered3.5.2.3 s1, 3.4.6 s1

SHALL requirements p. 1

SHALL The querying system SHALL be prepared to receive a Z31 response to either a Z34 or a Z44 query.		Missing Warning

The guide tells querying systems how to re-query after a user selects a candidate, but does not require them to accept a Z31 for a Z44 query. A system built to the earlier guide, where a Z44 could not get a Z31, may not.

Recommendation: Add to 3.5.2.3: "Querying systems SHALL be prepared to receive a Z31 response to either a Z34 or a Z44 query."

Action: Narrative

3.5.2.3 Z31 - Return a List of Candidates, 3.4.6 Selecting a Candidate Match, 3.4.2 Unified Z34 and Z44 Profile Model

MAY requirements; Out of scope p. 1

MAY IIS that already return a Z31 for both queries MAY continue; IIS that return one only for a Z34 MAY also return one for a Z44; IIS that do not return a Z31 for a Z34 MAY also not return one for a Z44. Whether an IIS returns a Z31, and what it contains, is IIS policy.		Covered

The guide says a Z31 is returned when "IIS policy allows limited identifying information for those candidates to be returned".

3.5.2.3 s1, 3.5.2.3 Z31 - Return a List of Candidates

Z31 compared with IGAMT p. 1

A Z31 MAY answer a Z44 query.		Conflict Issue

The IGAMT Z31 profile has IZ-67a ("QPD-1.1 shall contain the value 'Z34'") and IZ-67b (QPD-1.2 "Request Immunization History"). The RSP echoes the query's QPD, so a Z31 answering a Z44 fails validation. The Z33 profile already allows either query (IZ-71a and IZ-71b).

Recommendation: Replace IZ-67a and IZ-67b in the Z31 profile with the Z34-or-Z44 constraints used in Z33 (IZ-71a, IZ-71b).

Action: IGAMT

3.5.2.3 s1, 3.5 Response (RSP) Profiles

Background p. 1

The earlier guide named the Z31 only as a response to a Z34.		Partly covered Note

Section 3.5.1 says RSP content "SHALL be consistent with the profile requested (Z34 or Z44)" and names only Z32 and Z42 as defaults, without saying which responses each query can receive.

Recommendation: Add a short table to 3.5.1 or 3.5.2 of the responses each query can receive (Z34 → Z31, Z32, Z33; Z44 → Z31, Z33, Z42).

Action: Narrative
