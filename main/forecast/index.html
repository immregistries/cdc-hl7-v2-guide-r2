4.4.4.6 Forecast

Represents recommendations for future vaccinations generated by a Clinical Decision Support (CDS) engine. Forecast information is future-oriented and describes what vaccination(s) are recommended and when.

A single Forecast Order Segment Group will contain multiple forecast sets, each identified by a shared OBX-4 value. Forecast semantics and conformance requirements are defined in the Clinical Decision Support sections of this guide.

The following LOINC-coded observations may appear in OBX segments within this group:

Vaccine type - LOINC 30956-7

Status in immunization series - LOINC 59783-1

Reason for recommendation - LOINC 30982-3

Earliest date - LOINC 30981-5

Recommended date - LOINC 30980-7

Overdue date - LOINC 59778-1

Latest date - LOINC 59777-3

Schedule used - LOINC 59779-9

Series name - LOINC 59780-7

Total number of doses in series - LOINC 59782-3

Dose number of next event - LOINC 30973-2
