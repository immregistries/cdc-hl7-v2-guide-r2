4.5.1.1 Primary Patient Identifier for Exchange

Quality review 2 notes

Findings from automated and editorial checks, for the authors. Not part of the guide.

  • Note Statement s1 Statement repeats its conformance verb, so it may hold more than one requirement. Consider splitting it.qf-compound-statement-ac81a1c2
  • Note MIROW guide Data Quality Assurance in Immunization Information Systems (BR159 and BR160 - Medical record numbers): Partly covered. The guide requires the primary exchange identifier to be stable and never reassigned, but does not mention the two common errors MIROW names: a newborn sent with the mother's identifier, and a Social Security number used as the identifier.
    Partly coveredAction: Narrative
    Best practice A medical record number should stay unique to one patient and never be reassigned; a newborn should not be given the mother's medical record number; and a Social Security number should not be used as a medical record number.
    Recommendation In Primary Patient Identifier for Exchange, add that the identifier must not be the mother's identifier for a newborn, or a Social Security number (MIROW BR159 and BR160).

    See the MIROW comparison

    qf-mirow-dqa-40

Every submitting system uses a patient identifier to coordinate exchange with the IIS. The identifier used consistently for updates and queries is the primary exchange identifier. It does not need to be a formal medical record number, but it needs to remain stable while current and cannot be reassigned to another patient.

MR is the expected national baseline because it reflects longstanding IIS practice. PI provides an alternative when the sender uses a general patient identifier rather than a medical record number. An IIS may support a limited set of additional identifier types. The supported set is documented in the IIS profile or onboarding agreement; support for the full HL7 identifier-type table is not expected.

Conformance statements

  1. SHALLSending systems SHALL submit a primary exchange identifier for each patient and SHALL use the current identifier consistently in update and query transactions.⚑s1
  2. SHOULDIIS SHOULD support MR and PI as identifier types for the primary exchange identifier.s2
