4.5.2.2 Official Registry Name

Quality review 1 warning · 1 note

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Warning Statement s3 Statement combines SHOULD, SHOULD NOT. Each statement should carry one requirement so it can be tested and referenced on its own.qf-multi-verb-statement-5eb563b7
  • Note Statement s3 Statement is 64 words. Long statements are hard to test and cite.qf-long-statement-3b634d83

The Official Registry Name corresponds to what HL7 previously called the legal name. The term "official registry" emphasizes that the name should match as closely as possible the one found on official documents, such as a birth certificate, driver's license, or passport. This is typically the most stable and comparable name across systems.

The official registry name is generally required for establishing a record in an IIS. Submitters should still report records even if the official registry name is unknown; the IIS will decide whether to accept them based on local policy.

Conformance statements

  1. SHALLSystems SHALL send the closest representation of the patient's legal/official registry name using name type code 'L' when that name is available.s1
  2. SHALL NOTSystems SHALL NOT use the 'L' name type for names that are not intended to represent the legal or official registry name.s2
  3. SHOULDIf an 'L' name is provided, systems SHOULD place it in the first repetition of PID-5 to simplify processing. Systems SHOULD NOT send an empty first PID-5 repetition to reserve space for an 'L' name; the repetition should be omitted if no 'L' name is available, and alternate name types (e.g., alias or newborn placeholder) should be included as subsequent repetitions.⚑s3
  4. SHALLReceiving systems SHALL accept the 'L' name in any repetition.s4
  5. SHOULDIIS SHOULD preferentially use the 'L' (legal/official) name for record matching when it is available, but other name types (e.g., alias or placeholder names) remain acceptable inputs for matching in the absence of an 'L' name.s5
