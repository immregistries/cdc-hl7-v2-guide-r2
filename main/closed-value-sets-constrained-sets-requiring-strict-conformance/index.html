4.3.4 Closed Value Sets (Constrained Sets Requiring Strict Conformance)

Closed value sets prohibit local extension. Only values explicitly defined in the value set are permitted, even by local agreement. Closed extensibility is used where consistency is essential for correct processing, aggregation, or interpretation across systems.

Closed value sets may be either dynamic or fixed. Dynamic-closed sets (e.g., CVX) evolve centrally, while fixed-closed sets (e.g., RXA-21) do not evolve at all without a specification update.
