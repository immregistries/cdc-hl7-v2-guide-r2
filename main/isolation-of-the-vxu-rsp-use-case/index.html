5.11.5 Isolation of the VXU/RSP Use Case

VXU and QBP/RSP messages are effectively stranded legacy standards. Outside of IIS reporting, there is no active community using these message structures for new work. Internationally, jurisdictions that adopted v2 for immunizations either mirrored U.S. patterns (e.g., Ireland for COVID-19) or have since moved to FHIR. Because there is no shared infrastructure and no competing use cases, IIS implementers are a captured audience: attempting to maintain strict HL7 v2 alignment provides no practical benefit.
