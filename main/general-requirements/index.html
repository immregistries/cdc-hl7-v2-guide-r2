The IIS transport layer must implement the CDC WSDL in full and provide a single interface capable of handling both update and query transactions. In this context, an endpoint refers to the network service address through which trading partners send HL7 v2 messages to the IIS (commonly implemented as a SOAP service URL).

Conformance statements

  1. SHALLIIS SHALL implement and maintain conformance with the CDC WSDL Specification (2015).s1
  2. SHALLIIS SHALL expose a single SOAP endpoint supporting both update (VXU) and query (QBP) messages.s2
  3. SHALLIIS SHALL determine message type from the HL7 v2 content, not from SOAP endpoint selection.s3
  4. MAYIIS MAY offer additional SOAP endpoints for specialized or high-volume use but the primary endpoint SHALL support both operations.⚑s4
