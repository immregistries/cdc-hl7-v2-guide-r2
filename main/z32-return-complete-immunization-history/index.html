3.5.2.2 Z32 - Return Complete Immunization History

Quality review 1 warning

Findings from automated and editorial checks, for the authors and reviewers. Not part of the guide.

  • Warning Z32 (history only) contains evaluation and forecast groups. The narrative describes Z32 as the response to a history-only query (Z34); evaluation and forecast belong to Z42. The Z32 co-constraints include an "Immunization Evaluation Results" group for administered and historical doses, and an "Immunization Forecast Results" group for the no-vaccination group. Section 4.7.7.5 also points to "Chapter 7.1.4, Z32" for the evaluation LOINC codes.
    ConflictAction: IGAMT
    Narrative "This response represents the primary success case for history-only queries."
    IGAMT export
    • Z32 table 1 (RXA-20 NA, CVX 998): group Immunization Forecast Results O [0..*].
    • Z32 table 2 (RXA-20 CP/PA, CVX ≠ 998): group Immunization Evaluation Results S [0..*].
    Recommendation Remove the evaluation and forecast groups from Z32 (or state that Z32 may carry them) and correct the cross-reference in 4.7.7.5 to Z42.
    qf-igamt-z32-evaluation

A Z32 response indicates a successful query for a Z34 query. The IIS has identified a single, high-confidence patient match and is able to return the complete immunization history consolidated for that patient.

This response represents the primary success case for history-only queries. All known administered and historical immunizations associated with the patient are included, reflecting the IIS's authoritative record at the time of the query.
