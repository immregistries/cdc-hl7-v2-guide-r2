3.5.2.2 Z32 - Return Complete Immunization History

Quality review 2 warnings · 1 note

Findings from automated and editorial checks, for the authors. Not part of the guide.

  • Warning Z32 (history only) contains evaluation and forecast groups. The narrative describes Z32 as the response to a history-only query (Z34); evaluation and forecast belong to Z42. The Z32 co-constraints include an "Immunization Evaluation Results" group for administered and historical doses, and an "Immunization Forecast Results" group for the no-vaccination group. Section 4.7.7.5 also points to "Chapter 7.1.4, Z32" for the evaluation LOINC codes.
    ConflictAction: IGAMT
    Narrative "This response represents the primary success case for history-only queries."
    IGAMT export
    • Z32 table 1 (RXA-20 NA, CVX 998): group Immunization Forecast Results O [0..*].
    • Z32 table 2 (RXA-20 CP/PA, CVX ≠ 998): group Immunization Evaluation Results S [0..*].
    Recommendation Remove the evaluation and forecast groups from Z32 (or state that Z32 may carry them) and correct the cross-reference in 4.7.7.5 to Z42.
    qf-igamt-z32-evaluation
  • Warning SISC guidance Query Responses and Patient Protection (Guidance when implementing Release 1.5): Missing. The guide says a Z32 or Z42 returns "the complete immunization history", but never addresses withholding some doses for privacy, or the clinical risk of a history that looks complete but is not.
    MissingAction: Narrative
    Guidance A partial patient history is not recommended. In the absence of widespread support for dose-level protection, all doses should be returned if any doses are returned: a provider who takes a partial history for a full one may make an inappropriate clinical decision, and confidence in the IIS suffers.
    Recommendation In the consent sections or the Z32/Z42 sections, state that an IIS SHOULD NOT return a partial history to protect some doses: it returns either the whole history or a Z33.

    See the SISC guidance comparison

    qf-sisc-qrpp-02
  • Note SISC guidance Guidance for HL7 RSP Messages to Support Interoperability (Summary (Table 2)): Partly covered. The guide matches the profiles to these outcomes (figure 17 and the Z32, Z42, and Z33 sections) but does not give the QAK-2 values ('OK' and 'NF').
    Partly coveredAction: Narrative
    Guidance Profile and QAK-2 by outcome: no match, Z33 with 'NF'; one match, Z32 (to a Z34) or Z42 (to a Z44) with 'OK'.
    Recommendation Include the QAK-2 values when this is covered (see sisc-rsp-09).

    See the SISC guidance comparison

    qf-sisc-rsp-10

A Z32 response indicates a successful query for a Z34 query. The IIS has identified a single, high-confidence patient match and is able to return the complete immunization history consolidated for that patient.

This response represents the primary success case for history-only queries. All known administered and historical immunizations associated with the patient are included, reflecting the IIS's authoritative record at the time of the query.
