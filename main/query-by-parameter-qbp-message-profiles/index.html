3.4 Query by Parameter (QBP) Message Profiles

Query/response messaging is a central capability of Immunization Information Systems (IIS). While submission workflows ensure data is collected and maintained, querying is where the investment pays off, by making complete, authoritative immunization histories available at the point of care. This is how clinicians gain visibility into vaccinations administered outside their organization and make informed decisions about what to give next.

The canonical use case remains a clinician evaluating a patient for vaccination and querying the IIS to retrieve a consolidated history and clinical recommendations. That interaction, simple, timely, and reliable, drives patient safety, reduces unnecessary doses, and supports consistent application of immunization schedules.

Query interfaces also serve essential public health and programmatic functions. Common secondary uses include disease investigation, population vaccination-rate assessment (by geography, socioeconomic indicators, or race/ethnicity) to target outreach, school and program reporting, reminder/recall cohort generation, and program evaluation (for example, HPV vaccination analyses related to cancer prevention). As demand for these uses has grown, IIS have had to manage sustained, high-volume query traffic from both interactive and automated systems.

The prevailing model for accessing IIS data is request-driven: systems ask for data when they believe it is needed. This model delivers current information on demand but can lead to unnecessary re-querying when systems lack visibility into recent record changes. To preserve clinical usefulness while keeping interfaces responsive and sustainable, this section establishes a disciplined approach to querying that supports appropriate, scalable use of QBP interfaces.

IIS query interfaces remain critical even as data-sharing architectures evolve, for example, TEFCA and FHIR-based exchange. These developments expand exchange options but do not replace the need for reliable, well-governed query functionality for clinical care and public health.
