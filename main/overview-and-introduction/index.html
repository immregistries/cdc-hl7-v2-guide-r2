1 Overview and Introduction

This Implementation Guide (IG) defines the national standard for exchanging immunization data between Immunization Information Systems (IIS) and the Electronic Health Records (EHRs), pharmacy systems, school health systems, and other submitting/querying systems that report or request immunization data. It is based on HL7 Version 2.5.1 and represents the collective effort of a national community, EHR developers, IIS program staff, public health agencies, standards developers, and others, who have refined this specification over more than three decades of implementation experience.

This guide reflects a change in how the National IG is authored and maintained. Earlier releases were published primarily as narrative text, with computable constraints for testing derived separately and later. This release is authored directly from structured requirements in the Immunization Guide Authoring Management Tool (IGAMT), so that the documented requirements and the testable requirements are closely connected. See Document and Structure for a description of how this authoring approach shapes the organization of the guide.

This guide also reflects an effort to describe immunization messaging as it is actually implemented across the IIS community today, rather than preserving conformance to the base HL7 v2 standard where that conformance no longer serves real-world operations. Where this guide's usage designations, field semantics, or acknowledgement behavior diverge from the base HL7 v2 standard, those divergences are documented explicitly and reflect more than two decades of operational adaptation by IIS and their trading partners. See Compatibility with the HL7 v2 Base Standard for additional background.
