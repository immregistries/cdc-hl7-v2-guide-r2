Messaging Phone and Email;
Telecommunication Use Code and
Equipment Type Values

Executive Summary

Specifications for the representation of patient and next-of-kin phone numbers and email
addresses in VXU and QBP messages are provided.

    • The patient's primary phone number, if known, shall be submitted in the first
         sequence of the PID-13, QPD-9, or NK1-5 with a telecommunication use code from
         HL70201 and a telecommunication equipment type code from HL70202.

    • An email address, if known, shall be submitted in a subsequent sequence in PID-13,
         QPD-9, or NK1-5 using the telecommunication use code 'NET' (network email
         address) from HL70201 (no telecommunication equipment type code is needed for
         an email address).

    • The telecommunication use code values ‘PRN’ and ‘NET’ from HL70201 shall be
         supported.

    • The telecommunication equipment type values ‘PH’ and ‘CP’ from HL70202 shall be
         supported.

Additional detail on the PID-13 field definition, telecommunication use code value set, and
telecommunication equipment type value set is also provided.

Background

Patient and next-of-kin phone and email information may be messaged in the following
fields, using the Extended Telephone Number (XTN) data type:

    • PID-13 (Phone Number – Home)
    • QPD-9 (Patient home phone/PID-13: Patient home phone), and
    • NK1-5 (Phone Number)
There is a lack of clarity around how patient and next-of-kin phone types (landline, cellular
phone) and email addresses should be messaged using the XTN data type. Usage of values
within Telecommunication Use Code (HL70201) Value Set and the Telecommunication
Equipment Type (HL70202) Value Set are not defined in the National IG.

Scope

In scope
Use of the XTN data type in PID-13 and NK1-5 to communicate landlines, cellular phones,
and email addresses for both patients and next-of-kins.

Out of scope
The processes and checks that systems may use to collect and/or verify phone numbers
and/or email addresses.

Implications

    • Phone numbers do not need to be designated as a landline or cellular phone.
    • Systems should not rely on designation of whether a phone number is for a landline

         or a cellular phone within an HL7 message. Third party services may be used to
         support phone number verification and/or ability of a phone number to receive text
         messages.
    • IIS should assume that most phone numbers are for cellular phones, even if only
         designated as telephone numbers.

Examples

Primary phone for the patient in PID-13:

Primary phone for the patient:
         |^PRN^PH^^^406^5557896|

Primary phone and email for the patient in PID-13:

Primary phone and email address for the patient:
                   |^PRN^PH^^^406^5557896~^NET^^Elise.Wong@isp.com|

Primary phone, secondary phone, and email address for a newborn baby in PID-
13:

Primary phone, secondary phone, and email address for the point of contact for a newborn
baby in PID-13. This will usually be the same as information sent in NK1:

         |^PRN^CP^^^406^5557896~^ORN^PH^^^406^5554566
         ~^NET^^Elise.Wong@isp.com|

Patient with no primary phone and an email address in PID-13:

As specified in the National IG, the first repetition of PID-13 must be the primary phone
number. If there is only an email, send an empty repetition (“~”) where the primary phone
would otherwise be:

         |~^NET^^Elise.Wong@isp.com|
