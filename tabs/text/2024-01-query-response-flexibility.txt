Query Response Flexibility: Z31
Response for Z34 and Z44 Queries

Executive Summary

Clarification on use of the Return a List of Candidates (Z31 RSP) response is provided, with
indication that a Z31 RSP MAY be returned in response to a Request Evaluated
Immunization History and Forecast (Z44 QBP) query. With this clarification, a Z31 RSP MAY
be returned in response to a Z44 QBP and in response to a Request a Complete
Immunization History (Z34 QBP).

Background

The National IG indicates that a Return a List of Candidates (Z31 RSP) may be returned in
response to a Request a Complete Immunization History Z34 QBP. However, it does not
indicate that a Z31 RSP may be returned in response to a Request Evaluated Immunization
History and Forecast Z44 QBP. It is unclear why a Z31 response was not indicated for a Z44
query. There is no documented history or reasoning to support this decision. Furthermore,
several immunization information systems (IIS) return a Z31 for both queries.

Scope

In scope
Return of a Z31 response message for either a Z34 or Z44 query.
Out of scope
Whether an IIS will return a Z31 response for a Z34 or Z44 query and the contents of a Z31
response. These are determined by IIS policy and business rules.

Clarifications and Conformance Expectations

SHALL requirements:
    • The querying system SHALL be prepared to receive a Z31 response to either a Z34
         or Z44 query.

MAY requirements:
    • IIS that return a Z31 response to both a Z34 and Z44 query MAY continue to do so.
    • IIS that return a Z31 response only for a Z34 query MAY also return a Z31 response
         for a Z44 query.
    • IIS that do not return a Z31 response for a Z34 query MAY also not return a Z31
         response for a Z44 query.
