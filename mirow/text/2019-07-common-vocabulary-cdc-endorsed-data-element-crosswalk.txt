Description CDC Endorsed Data Element terms that are a match to a MIROW Common
                   Vocabulary term, either directly or indirectly

This report contains two parts. Both parts are listed in alphabetical order of the CDC
Endorsed Data Element terms:

    • Part One – The first part of the report lists CDC Endorsed Data Element terms that
         are considered a direct match to a term in the MIROW Common Vocabulary.

    • Part Two – The second part of the report lists CDC Endorsed Data Element terms
         that are not a direct match but are otherwise related to a MIROW Common
         Vocabulary term, also known as a “fuzzy match.”
