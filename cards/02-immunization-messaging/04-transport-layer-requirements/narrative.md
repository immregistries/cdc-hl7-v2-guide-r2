Reliable, standardized message transport is essential for interoperability between Immunization Information Systems (IIS) and their trading partners.

While the HL7 Version 2 standard defines message content, it does not specify transport. The CDC WSDL Specification (2015) [4] provides a uniform SOAP-based transport mechanism for HL7 v2.5.1 immunization messages and is now universally implemented across IIS. Building on this foundation, IIS may publish their own local guidance that aligns with the CDC WSDL, while also describing how high-volume submitters can avoid system overload during peak times.

This section confirms that all IIS SHALL support the CDC WSDL as a valid, standards-based option for message transport. The CDC WSDL remains the authoritative reference for message operations and security; this guide defines additional operational requirements for consistent use across jurisdictions.
