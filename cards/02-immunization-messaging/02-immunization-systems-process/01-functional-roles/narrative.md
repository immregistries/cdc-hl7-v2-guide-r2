- **Submitting system**s report vaccination data to the IIS.
- **Querying systems** request immunization records and/or recommendations from the IIS.

A system may fulfill one or both roles.

This guide defines the HL7 v2.5.1 interactions between IIS and these submitting/querying systems. It does not distinguish between the internal structure or certification of the submitting system, nor does it assume uniformity in configuration or workflow.
