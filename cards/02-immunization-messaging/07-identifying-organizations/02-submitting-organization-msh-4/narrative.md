A **submitting organization** is an organization operating a single software system instance (for example, an EHR, gateway, or service bureau node) that sends immunization data to the IIS over one authenticated connection. The submitting organization may submit data for itself or, when explicitly authorized during onboarding, submit on behalf of other organizations. This reflects common gateway or service-bureau architectures and remains permitted; regardless of how many responsible organizations are represented within the submitted data, MSH-4 always identifies the submitting organization operating the interface, not the organization responsible for the connection.

This section defines the semantic role of the submitting organization identifier within the HL7 v2 message; it does not prescribe how jurisdictions must structure authentication credentials or submission architectures. Authentication occurs at the transport layer (e.g., CDC WSDL), where credentials such as usernames, certificates, or whitelisted IPs establish the identity of the submitting organization. While the specific transport-layer authentication mechanisms used to establish this identity may vary across jurisdictions, within the HL7 v2 message, MSH-4 (Sending Facility) carries the organizational identifier that corresponds to this authenticated identity, and must consistently identify the submitting organization responsible for the connection. This value is required because it is always known for an authenticated interface, and requiring it ensures consistent identification of the submitting organization across implementations. While transport credentials and MSH-4 values do not need to be textually identical, they must unambiguously resolve to the same submitting organization as defined during onboarding.

This guide defines the meaning of identifiers within HL7 v2 messages, not the operational architecture used by IIS or systems. Different jurisdictions implement different credential-management or gateway models, but the HL7 v2 message consistently communicates the submitting organization through MSH-4.
