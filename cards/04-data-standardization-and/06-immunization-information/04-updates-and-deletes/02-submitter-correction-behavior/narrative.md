An update refers to the same source record and carries the same ORC-3. A delete also refers to the original source record and carries the ORC-3 and identifying field values previously submitted for that record. When a rechart creates a replacement source record, the replacement add carries the identifier assigned to the replacement record.

Changes to fields outside the identifying fields list can be sent as updates. The correction message can include other current vaccination information even when those additional fields did not trigger the correction.
