The vaccine type must be reported first for each evaluation. An evaluated group is the set of OBX observations that together express the evaluation for a single antigen or series component; a single RXA may contain multiple evaluated groups when a dose is assessed for multiple antigens. For example, Pediarix (CVX 110) may be evaluated as DTaP (CVX 106), Hep B (CVX 08), and IPV (CVX 10), each as a separate evaluated group. Only a single LOINC observation identifier is used to identify the evaluated antigen, and the component-level vaccine-type LOINC code is no longer used.
