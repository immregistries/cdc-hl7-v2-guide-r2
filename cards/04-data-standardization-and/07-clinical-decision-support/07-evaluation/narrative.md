Evaluation communicates how each administered vaccination is assessed against one or more immunization series. A single vaccination may be evaluated for multiple antigens, particularly for combination products. For example, an administration of Pediarix (CVX 110) may be evaluated as the component antigens DTaP (CVX 106), Hep B (CVX 08), and IPV (CVX 10), with each component assessed separately. Evaluation information is conveyed through a consistent set of observations within the vaccination history order group. The vaccine type must always be identified, followed by dose validity, and then any available supporting details.

When indicating the vaccine type evaluated, the CVX code chosen should be the CVX that most closely matches the product or antigen evaluated. CDS engines commonly use an unspecified CVX code when an exact product formulation is not known. The CVX used reflects how the CDS engine interprets the dose for evaluation, which may not always match the original CVX submitted for the vaccination. No interface-level requirement mandates support for every product-level CVX; CVX support and local mappings are implementation decisions for each CDS engine.

Dose validity is represented by the values Y and N only. A value of Y indicates that the vaccination counts toward completion of the specific series being evaluated. A value of N indicates that the vaccination does not count toward that series. N does not imply improper administration; combination vaccines may include components that do not count toward certain antigen series even when the dose was clinically appropriate.

Additional evaluation elements provide useful context but are not fully standardized in this version of the guide, and their meaning may vary by CDS implementation. Series name, dose number, total number of doses in series, and schedule used can help systems interpret how a CDS engine reached its conclusions, but these values should be used cautiously and without assuming consistent semantics across registries.
